# 常见错误码速查

## 通用错误码

| 错误码 | 错误信息 | 原因 | 解决 |
|--------|---------|------|------|
| 1000001 | access_token 无效或已过期 | token 过期或缓存失效 | 清除 token 缓存后重试（见下方排查建议） |
| 99991672 | 权限不足 | 应用缺少所需 scope | 在飞书开放平台申请对应权限并重新发布应用 |
| 112005 | app 身份权限不足 | 当前身份（bot/user）权限不够 | 切换身份或申请对应 scope |
| 1130001 | 应用未开通该权限 | scope 未在应用后台开通 | 开通权限后重新发布 |
| 2091001 | 参数无效 | 请求参数类型或格式错误 | 检查参数类型和必填项 |
| 2091002 | 资源不存在 | token 或 ID 不正确 | 检查 token 是否拼写正确 |
| 2091005 | 无权访问该资源 | 分享设置或权限配置问题 | 检查文档/表格的分享设置 |

## 多维表格错误码

| 错误码 | 错误信息 | 原因 | 解决 |
|--------|---------|------|------|
| 1254015 | Field types do not match | 字段值格式与类型不匹配 | 先 `base_fields.py` 查看类型，按字段类型表构造正确格式 |
| 1254041 | Excel 数据区域非法 | sheet 范围格式错误 | 检查 range 格式，如 `A1:B2` |
| 1254045 | FieldNameNotFound | 字段名不存在 | 检查字段名（含空格、大小写），或用 `base_fields.py` 确认 |
| 1254064 | DatetimeFieldConvFail | 日期格式错误 | 必须用毫秒时间戳（13 位），不能用字符串或秒级时间戳 |
| 1254066 | UserFieldConvFail | 人员字段格式错误 | 必须传 `[{"id": "ou_xxx"}]`，确认 user_id_type |
| 1254068 | URLFieldConvFail | 超链接格式错误 | 必须用对象 `{"text": "...", "link": "..."}`，不能传字符串 URL |
| 1254104 | RecordAddOnceExceedLimit | 批量超过上限 | 分批，每批 ≤ 500 条 |
| 1254291 | Write conflict | 并发写冲突 | 串行调用 + 延迟 0.5~1 秒 |
| 1254303 | AttachPermNotAllow | 附件未属于当前表格 | 附件需通过 `parent_type=bitable_file` 上传到当前多维表格 |
| 99992402 | field validation failed | 字段更新参数不完整 | 必须同时传入 `type`（CLI 已自动处理） |

## 通讯录错误码

| 错误码 | 错误信息 | 原因 | 解决 |
|--------|---------|------|------|
| 112005 | app 身份权限不足 | 通讯录敏感信息需要 user_access_token | 确保 `credentials.json` 中已配置 `userAccessToken`，或运行 `python3 feishu-auth/auth_get_user_token.py` |

## 排查建议

1. **先检查 token 和 ID**：大部分 404/资源不存在错误都是拼写问题
2. **再检查权限**：遇到 99991672 或 112005，去飞书开放平台确认 scope 已开通并重新发布应用
3. **清除 token 缓存**：删除运行时配置目录中的 `.token_cache.json`（平台环境在 `runtime_credentials/feishu-skills/`，本地在 `config/`）
4. **确认字段类型**：写入 Base 前先 `base_fields.py` 查看字段结构
5. **查看完整错误**：CLI 会输出完整错误响应，包含飞书返回的原始错误信息
